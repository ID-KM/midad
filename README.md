# مداد — قارئ الكتب العربي

> **«اقْرَأْ بِاسْمِ رَبِّكَ الَّذِي خَلَقَ»** — العلق: 1

تطبيق أندرويد لقارئ الكتب بالعربية — اقرأ كتب PDF و EPUB براحة، ابحث في مكتبة Archive.org، وبنِّ مكتبتك الخاصة.

---

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 📖 **قارئ PDF** | عرض سلس مستمر بين الصفحات، حفظ تلقائي لموضع القراءة |
| 📚 **قارئ EPUB** | دعم كامل للغة العربية (RTL)، تحكم بحجم الخط، فصول متصلة |
| 🔍 **بحث في Archive.org** | مكتبة ضخمة من الكتب العربية المجانية — تحميل مباشر من التطبيق |
| ⬇️ **تحميل ذكي** | إشعار بمرور التحميل + إمكانية الإيقاف في أي لحظة |
| 📁 **حفظ في مجلد عام** | الكتب تظهر في `Download/مداد` — تصل إليها من أي مدير ملفات |
| 🌙 **وضع العين المريحة** | حماية العين + تعديل الشدة + ثيم ليلي محفوظ |
| 📝 **ملاحظات** | أضف ملاحظات لكل صفحة واقفز إليها بضغطة |
| 🔖 **مفضلة** | رتّب مكتبتك وأضف علامات للكتب المهمة |

## 🚀 البدء

```bash
flutter pub get
flutter run
```

### البناء للمشاركة

```bash
export ANDROID_HOME="$HOME/android-sdk"
flutter build apk --release --split-per-abi
```

الملفات الناتجة في `build/app/outputs/flutter-apk/`:
- `app-arm64-v8a-release.apk` — معظم الهواتف الحديثة
- `app-armeabi-v7a-release.apk` — الهواتف القديمة 32-bit
- `app-x86_64-release.apk` — المحاكيات

## 🏗️ التقنيات

- **Flutter** — واجهة عربية RTL كاملة
- **pdfrx** — عرض PDF سريع (محرك PDFium)
- **Archive.org API** — البحث والتحميل المجاني
- **SharedPreferences** — حفظ المظهر والإعدادات
- **flutter_local_notifications** — إشعارات التحميل

## 📁 بنية المشروع

```
lib/
├── core/          # الثيم وحماية العين
├── data/          # النماذج والخدمات (Archive، EPUB، الإشعارات)
```
